# Safe AI: descargas

Safe AI es un programa para Windows que **borra los datos personales de tus documentos** (nombres, RUT, teléfonos, correos, direcciones, fechas de nacimiento y diagnósticos) antes de compartirlos o usarlos con IA. Funciona en tu computador, sin internet, y no guarda tus documentos.

Este repositorio solo publica los instaladores. El código fuente se mantiene aparte.

## Descargar

👉 **[Última versión](https://github.com/nikopradopalma17-art/safe-ai-releases/releases/latest)**: descarga `SafeAI-Setup-X.Y.Z.exe`.

## Guías

- [Guía de usuario](docs/guia-usuario.md): instalar, usar, límites y actualizaciones.
- [Aviso de privacidad](docs/privacidad.md): qué hace con tus datos y qué no.
- [Verificar el instalador](docs/verificar-instalador.md): para TI, cómo comprobar la huella SHA-256.

> **Importante:** el programa no detecta el 100% de los datos. Revisa siempre el resultado antes de compartirlo.
